Install DeSurface

Drag DeSurface.app onto Applications.

Updating an older installation

1. Quit the app.
2. Drag DeSurface.app from this disk image onto Applications and choose Replace.

Some earlier releases were installed as SolveCraft.app. Move that one to the Trash
once DeSurface.app is in Applications, and replace any Dock shortcut with the
old name (open DeSurface.app, then choose Options > Keep in Dock).

Designs saved as .solvecraft still open, and DeSurface copies your settings
and recovery files from the old SolveCraft folder on its first launch.
New designs are saved as .desurface.
